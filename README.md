# Cramer's Rule in MIPS Assembly

> Supporting — Computer Engineering · Birzeit University Computer Engineering portfolio

A MIPS assembly exercise that solves linear equations using Cramer's rule and file-based input/output.

## What this demonstrates

- MIPS assembly
- numerical methods
- low-level programming
- file I/O

## Repository contents

The implementation is stored under `renaming edits`; sample input and output are included.

## Getting started

Run the assembly source in the MIPS simulator used by the course and provide `input.txt`.
